# Архитектор Дизайн

Локальное приложение для работы над задачей в четыре этапа. Задайте название, исследуйте проблему, разберите варианты решения и метрики, затем соберите дизайн-документ. Каждый этап можно открыть отдельно из списка задач. Настройки AI и редактируемые методики сохраняются на этом компьютере.

AI учитывает текущий ввод и сохранённые материалы других этапов той же задачи. Начать можно с любого этапа. Для решений и черновика документа можно описать задачу прямо в запросе. Предложенные изменения применяются после вашего выбора.

## Запуск

Требуется Python 3.11 или новее. Дополнительные библиотеки для запуска не нужны.

```sh
git clone https://github.com/foyreet/architector-design.git
cd architector-design
python3 run_local.py
```

В Windows используйте `py run_local.py`. Откроется [список задач](http://127.0.0.1:8771/). Параметры запуска — `--port` и `--no-browser`. В списке задач нажмите «Настройки AI», чтобы выбрать совместимый API или войти через Codex. Для ручного редактирования подключение модели необязательно.

Подробные примеры работы с этапами — в [руководстве](GUIDE.md).

## Перенос существующих задач

До создания первой задачи выполните из нового репозитория:

```sh
python3 migrate_design.py "/путь/к/Архитектор/data/workspace/local/documents.sqlite3"
```

Скрипт копирует сохранённые документы, деревья, кейсы, связи и методики в пустое хранилище. Старая база открывается для чтения. Несохранённые браузерные черновики сохраните в старом приложении до перехода. Подключение AI настройте отдельно. Для резервной копии остановите приложение и сохраните его папку `data/`. Переменная окружения `ARCHITECT_DESIGN_DATA_DIR` задаёт другую папку данных.

## Пространство проблем

Откройте список «Задачи» и выберите этап «Проблемы» нужной задачи. Нажмите на корень для ввода формулировки проблемы, затем добавьте общий вопрос вручную или через AI. У каждого вопроса есть ответ и до двух последующих уровней уточнения.

«Сохранить» записывает дерево отдельно. Открыть другую задачу или создать новую можно в списке «Задачи». Для импорта и экспорта JSON нажмите на корень дерева. Деревья из ранее сохранённых дизайн-документов появляются здесь автоматически.

## Пространство решений

Запишите ответы в дереве и нажмите «Пространство решений». Кнопка «Разбить на кейсы с AI» передаёт подключённой модели задачу и заполненные ответы. Для каждой подзадачи модель предлагает критерий готовности, подход и обоснование с привязкой к ответам. Предложения можно принять, отредактировать и сохранить рядом с исходным деревом.

В каждом кейсе доступны два редактируемых запроса — по бизнес-задаче и техническим требованиям. «Найти аналоги в интернете» запускает веб-поиск по внедрениям и неудачам, а также поиск публикаций в arXiv и Crossref и реализаций на GitHub. Модель оценивает найденные заголовки, аннотации и поисковые фрагменты, отдельно объясняет оба вида сходства и предлагает, что проверить перед переносом. У источников с известным исходом показывается выдержка. После поиска нажмите «Сохранить кейсы».

## Иерархия метрик

В строке задачи откройте этап «Метрики». Нажмите на корень, чтобы записать бизнес-цель. Добавляйте метрики и дочерние ветви, указывайте формулу, единицы, данные и окно измерения. В каждой карточке можно описать связь с родителем и способ её проверки. Кнопка «Предложить метрики с AI» позволяет предварительно просмотреть и добавить предложение к цели или выбранной метрике. Сохранённые деревья доступны в библиотеке режима и поддерживают обмен через JSON.

## Черновик и ревью дизайн-документа

В разделе «Датасет» после метрик кнопка «Вставить структуру» добавляет четыре подзаголовка — ETL, фильтрацию, генерацию признаков и разметку. В подразделе «Генерация признаков» укажите, что получает модель в момент прогноза.

В редакторе нажмите «Собрать черновик», выберите дерево проблем с нужными кейсами, иерархию метрик или оба источника. В разделе «Метрики» модель связывает показатель успеха с бизнес-целью, описывает измерение и проверку прокси. Раскройте «Источники раздела», чтобы увидеть версию и определения использованных метрик. Прочитайте предложенный текст и его источники. Пустые разделы отмечены для заполнения, а замену существующего текста нужно выбрать отдельно. Нажмите «Применить выбранные разделы», затем «Сохранить». При изменении связанных источников редактор подскажет, какие разделы стоит пересмотреть.

«Провести ревью» передаёт подключённой модели текущий текст, включая несохранённые правки, и исходные определения метрик из принятых разделов. У каждого вопроса есть цитата из раздела и пояснение, почему вопрос важен.


Схемы и запуски экспериментов доступны в [Архитекторе](https://github.com/foyreet/architector).
